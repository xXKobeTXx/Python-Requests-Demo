Requests Module Demo
====================

This repository introduces the ``requests`` module, a popular Python library
used for sending HTTP requests and interacting with web APIs.

Installation
------------

The ``requests`` module is not included in the Python standard library.
Install it using pip:

.. code-block:: bash

    pip install requests

How to Run the Example
----------------------

1. Download or clone this repository.
2. Install the ``requests`` module using the command above.
3. Run the example script:

.. code-block:: bash

    python example.py

You should see a JSON response from the GitHub API.
